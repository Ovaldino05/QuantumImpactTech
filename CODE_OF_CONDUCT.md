# Código de Conducta / Code of Conduct

Este proyecto adopta el [Contributor Covenant 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).

**ES** — Nos comprometemos a que la participación sea libre de acoso para todas las personas. Se espera trato respetuoso, crítica constructiva y aceptación de responsabilidad. No se toleran insultos, acoso, ni publicación de datos privados de otras personas.

**EN** — We pledge a harassment-free experience for everyone. Be respectful, give constructive feedback, own your mistakes. Insults, harassment and doxxing are not tolerated.

Reportes / Reports: usa la mensajería privada de GitHub con [@Ovaldino05](https://github.com/Ovaldino05). Se tratarán con confidencialidad.
