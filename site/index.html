schema-caniuse

Can I use this JSON Schema with OpenAI, Claude or Gemini? Every provider accepts a different subset of JSON Schema, and every framework keeps its own outdated list. schema-caniuse is one shared, sourced, versioned dataset plus a zero-dependency checker and CLI.
